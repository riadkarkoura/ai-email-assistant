AI Email Assistant

A beginner automation project built with JavaScript and n8n.

Features

* Analyze email content
* Detect email importance (High / Medium / Low)
* Save email logs locally
* Send data to n8n using Webhooks
* Filter important emails using IF conditions
* Send Telegram notifications for high-priority emails

Workflow

Website → Webhook → Code → IF → Telegram

Technologies Used

* HTML
* CSS
* JavaScript
* n8n
* Telegram Bot API

Example

Input:

urgent: client needs invoice today

Output:

Importance: High

Telegram notification sent automatically.
